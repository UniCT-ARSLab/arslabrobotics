================
 arslabrobotics
================

A set of python libraries and examples to simulate and implement robotic systems
================================================================================

Installation
------------

Clone the repository::

  $ git clone https://github.com/UniCT-ARSLab/arslabrobotics

then enter the directory and install the binary libraries::

  $ cd arslabrobotics
  $ pip install dist/arslabrobotics-2.0.0-py3-none-any.whl
