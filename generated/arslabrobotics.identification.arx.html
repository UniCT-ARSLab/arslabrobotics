An helper class to solve the linear system identification problem using the auto-regressive model:

y(k) + a0 * y(k-1) + a1 * y(k-2) + ... y(k-n) = b0 * u(k) + b1 * u(k-1) + ... u(k-m)
Parameters:

  • data_in_out – A matrix [ [ u(k), y(k) ] ] containing input/output sampled data

  • output_lag – The number of delay blocks for the output (n)

  • input_lag – The number of delay blocks for the input (m)
