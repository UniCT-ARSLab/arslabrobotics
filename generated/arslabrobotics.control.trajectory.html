class arslabrobotics.control.trajectory.StraightLineMotion(_vmax, _acc, _dec, angles_index=-1)[source]

Bases: object

This class performs a linear motion over a generic n-dimensional space form a point start to a point end.

Start and end are supposed to be robot poses made of cartesian coordinates and angles.

Initializes the trajectory

angles_index specifies the element in the pose where the angles start. For example, in a 2D where the pose is (x,y,theta), angles_index would be 2.

Parameters:

  • _vmax (float) – the maximum speed

  • _acc (float) – the acceleration

  • _dec (float) – the deceleration

  • angles_index – the index in the pose where the angles start
